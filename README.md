# Proyecto Final: Docker, Kafka y Spark

Procesamiento en tiempo real usando Kafka como broker de mensajes y Spark
Structured Streaming como consumer, todo levantado con Docker Compose.

## Contenido
- `docker-compose.yml` — servicios: Zookeeper, Kafka, Jupyter (PySpark)
- `notebooks/streaming.ipynb` — notebook de Spark Streaming
- `informe.pdf` — respuestas de la Parte 1 y evidencia de la Parte 2
